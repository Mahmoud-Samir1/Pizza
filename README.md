# 🍕 Pizza Ordering System

A simple Pizza Ordering System built using **C# and Windows Forms (WinForms)** as a practical project for improving problem-solving, programming logic, and GUI development skills.

## 📌 About The Project

This project simulates a simple pizza ordering system where the user can customize their pizza by selecting different options and get a summary of their order with the final price.

The main goal of the project was not only to build the application, but also to practice how to break a problem into smaller parts and implement each part step by step.

## ✨ Features

- 🍕 Choose pizza size:
  - Small
  - Medium
  - Large

- 🥖 Choose crust type:
  - Thin Crust
  - Thick Crust

- 🧀 Choose additional toppings:
  - Extra Cheese
  - Mushrooms
  - Tomatoes
  - Onion
  - Olives
  - Green Peppers

- 🍽️ Choose where to eat:
  - Eat In
  - Take Out

- 🔢 Choose the required quantity.

- 📋 Display a summary of the selected order.

- 💰 Calculate the total price automatically.

- 🔄 Reset the form and start a new order.

## 🛠️ Technologies Used

- C#
- .NET
- Windows Forms (WinForms)
- Object-Oriented Programming (OOP)
